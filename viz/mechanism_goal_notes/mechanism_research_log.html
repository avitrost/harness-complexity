Known Design Corrections Before Next Evals

Patch ablation has been fixed in code. The new codex_full_no_patch_affordance profile removes the explicit tool, removes model-visible apply_patch prompt guidance, and blocks shell apply_patch interception.

Unified-output ablation has been fixed in code. The new codex_full_raw_exec_output profile renders only raw stdout/stderr as model-visible command output while holding the Codex tool loop otherwise fixed.
