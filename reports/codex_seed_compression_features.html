Reading left to right: early compression removes readability and structure first; later compression removes behavior. The 700-line seed is the first major behavioral break because model compaction is gone. The 400-line seed keeps the Codex prompt and core shell tools but drops plan updates and most metadata. The 100-line endpoint is a minimal baseline, not a Codex port.

Compression Steps

Step Physical LOC What changed Behavioral cost
Full 2210 Readable high-fidelity Codex port with manifest, profiles, compaction, four tools, AGENTS and environment context. Reference point.
Compressed 1660 Large prompt/schema text packed; helper classes shortened; same default behavior targeted. Mostly maintainability cost, little intended behavior loss.
1300 1300 Retains all four tools, model compaction, AGENTS, metadata, recovery; removes readable parity scaffolding and many named abstractions. Less inspectable, thinner tool-router edge cases.
1000 1000 Further helper consolidation and shorter operating guide; still keeps model compaction and full tool surface. More brittle normalization and fewer diagnostics.
700 700 Model compaction removed; history is bounded and clipped. Four tools, AGENTS, permissions, and recovery remain. Long-horizon tasks lose the Codex-style summarization path.
400 400 Plan tool removed; history becomes recent-window replay plus a synthetic compacted-transcript note. Core prompt, AGENTS, exec, patch, write_stdin stay. Weaker collaboration planning, weaker long-context memory, sparse metadata.
100 100 Generic minimal agent: exec_command only, plain task prompt, recent terminal text, final text means done. Not an explicit Codex compression; useful as a floor for LOC-axis experiments.

Sources: seed harnesses in seeds/, README compression-track notes, and the Tufte visualization skill guidance for high data-ink, direct labels, small-multiple comparison, and minimal decoration (gist).
